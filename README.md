# Schedly
Schedly is a dynamic mobile scheduling app that turns schedule screenshots into smart, reminder-ready timetables. Built for students, teachers, and shift-based workers (mall staff, government employees, fast-food crew), Schedly solves a simple but universal problem: people forget their class, duty, or shift times.

Users simply import a screenshot of their existing schedule — whether it's a class timetable, a work shift roster, or a duty schedule — and Schedly extracts the details using OCR and AI-powered parsing, then converts it into a clean, editable schedule. From there, Schedly automatically sets alarms and reminders ahead of each scheduled event, so nothing gets missed.

Unlike rigid calendar apps, Schedly is built to be generic and adaptive — one app that works whether you're a student tracking classes, a teacher managing a teaching load, or an employee juggling rotating shifts.

Key features:

Screenshot-to-schedule import (OCR + AI parsing via Cloud Vision & Claude API)
Editable review screen before saving — user stays in control of accuracy
Customizable reminders/alarms with adjustable lead time
Supports recurring weekly schedules and one-time entries
Built for real-world Philippine use cases: school, mall, government office, and fast-food shift work
